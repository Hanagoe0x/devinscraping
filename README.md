# Mastra Scraping Agent Project

This project demonstrates a web scraping agent built using the Mastra AI agent development framework. It includes a basic weather agent and a more complex scraping agent capable of handling logins and saving content as PDFs.

## Project Structure

-   `src/`: Contains the main source code.
    -   `index.ts`: The main entry point to run the application and interact with agents via the command line.
    -   `mastra/`: Mastra-specific configurations, agents, and tools.
        -   `index.ts`: Mastra instance configuration, registering available agents.
        -   `agents/`: Contains the agent definitions.
            -   `weather-agent.ts`: A simple agent to get weather information (using a mock tool).
            -   `scraping-agent.ts`: An agent that uses Playwright to scrape websites based on depth.
            -   `range-scraping-agent.ts`: An agent specialized for scraping URL ranges based on IDs.
        -   `tools/`: Contains the tool definitions used by agents.
            -   `weather-tool.ts`: A mock tool to provide weather data.
            -   `playwright-scrape-tool.ts`: Tool using Playwright for depth-based web scraping and PDF generation.
            -   `playwright_scrape_range_tool.ts`: Tool using Playwright for scraping URL ranges and saving as PDFs.
-   `package.json`: Project dependencies and scripts.
-   `tsconfig.json`: TypeScript configuration.
-   `.env`: Environment variables (requires `GOOGLE_GENERATIVE_AI_API_KEY`).
-   `scraped_pdfs/`: Default output directory for PDFs generated by the scraping agent (created automatically).

## Setup

1.  **Clone the repository (if applicable).**
2.  **Install dependencies:**
    ```bash
    pnpm install
    ```
3.  **Install Playwright browsers and dependencies:**
    ```bash
    pnpm exec playwright install --with-deps
    # If the above command shows missing system dependencies, run:
    # sudo apt-get update && sudo apt-get install -y libgles2 gstreamer1.0-libav
    ```
4.  **Create a `.env` file** in the project root and add your Google Gemini API key:
    ```env
    GOOGLE_GENERATIVE_AI_API_KEY=YOUR_GEMINI_API_KEY
    ```

## Running the Application

1.  **Start the application:**
    ```bash
    pnpm start
    ```
2.  The application will prompt you to select an agent (`weatherAgent`, `scrapingAgent`, or `rangeScrapingAgent`).
3.  Type the name of the agent you want to interact with (e.g., `rangeScrapingAgent`).
4.  Interact with the selected agent by typing your requests.
5.  Type `switch <agent_name>` (e.g., `switch weatherAgent` or `switch rangeScrapingAgent`) to change agents during the session.
6.  Type `exit` to quit the application.


## Using the Range Scraping Agent (`rangeScrapingAgent`)

This agent is specialized for scraping a sequence of pages based on an ID pattern in the URL (e.g., articles, posts, magazines).

**Functionality:**

-   Takes a base URL pattern with an `{id}` placeholder.
-   Takes a start ID and an end ID.
-   Iterates through all IDs in the specified range, constructing the full URL for each.
-   Optionally handles login using provided credentials and CSS selectors before starting the range scrape.
-   Saves each successfully scraped page as a PDF file, named by its ID.
-   Optionally checks for a CAPTCHA element on each page and skips if found.
-   Stores PDFs in a subdirectory named after the hostname and a specific folder (e.g., `magazines`).

**How to Interact:**

1.  Start the application (`pnpm start`) and select `rangeScrapingAgent`.
2.  Make a request, specifying the base URL pattern, start ID, and end ID. For example:
    `scrape range from https://example.com/article/{id} starting at 100 ending at 200`
3.  The agent will ask you to confirm the parameters:
    -   Base URL Pattern
    -   Start ID
    -   End ID
    -   Whether login is required.
4.  **If login IS required**, the agent will prompt for:
    -   Login Page URL (optional, defaults to the first URL in the range)
    -   Username
    -   Password
    -   Username Field CSS Selector
    -   Password Field CSS Selector
    -   Login Button CSS Selector
    -   (Optional) CAPTCHA Check CSS Selector
5.  Provide the necessary details when prompted.
6.  Confirm the final parameters by typing `yes`.
7.  The agent will execute the scraping process using Playwright. PDFs will be saved to a subdirectory like `scraped_pdfs/<hostname>/magazines/` by default.


## Using the Scraping Agent (`scrapingAgent`)

The `scrapingAgent` uses the `playwright_scrape_website` tool to scrape web pages.

**Functionality:**

-   Navigates to a starting URL.
-   Optionally handles login using provided credentials and CSS selectors.
-   Scrapes pages up to a specified depth, following links within the same domain.
-   Saves each scraped page as a PDF file.
-   Preserves the website's directory structure within the output folder.

**How to Interact:**

1.  Start the application (`pnpm start`) and select `scrapingAgent`.
2.  Make a request, specifying the target URL and desired depth. For example:
    `scrape https://example.com with depth 1`
3.  The agent will ask you to confirm the parameters:
    -   Starting URL
    -   Scraping Depth
    -   Whether login is required.
4.  **If login IS required**, the agent will prompt for:
    -   Login Page URL (if different from the start URL)
    -   Username
    -   Password
    -   Username Field CSS Selector
    -   Password Field CSS Selector
    -   Login Button CSS Selector
    -   (Optional) CAPTCHA Check CSS Selector (e.g., `iframe[title*="captcha"]`)
5.  Provide the necessary details when prompted.
6.  Confirm the final parameters by typing `yes`.
7.  The agent will execute the scraping process using Playwright. PDFs will be saved to the `scraped_pdfs/<hostname>/` directory by default (or the directory specified in the tool input).
